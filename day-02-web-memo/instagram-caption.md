## 본문 (복사해서 붙여넣기)

어제 읽은 그 문서, 오늘 또 처음부터 읽으셨죠? 🔁

공개 MCP 두 개를 섞었습니다.
Fetch MCP(웹페이지 → 본문) + Memory MCP(엔티티·관계·관찰) → **web-memo** (5 tools)

문제는 이거였어요.
문서 한 장은 통째로 받으면 2,000토큰. 바뀐 건 요금 한 줄인데 매번 2,000토큰을 다시 씁니다.

그래서 **URL 하나**를 접점으로 붙였습니다.
· Fetch가 → 지금 본문을 가져오고
· 스냅샷이 → 지난 본문과 비교해 **바뀐 줄만** 남기고
· 기억 그래프가 → 그 페이지에 대해 내가 한 말을 붙듭니다

실측: 1,867토큰짜리 변경 이력 페이지에서 두 줄 수정 + 한 줄 추가
→ 전체 1,903토큰 대신 **298토큰**만 받았습니다 (-1,605)

같은 내용이면 아무것도 저장하지 않습니다. "변경 없음" 한 줄로 끝.

툴 5개 👇
1️⃣ remember_page — 읽고 기억, 바뀌었으면 diff만
2️⃣ page_changes — 저장된 두 스냅샷 비교 (네트워크 0회)
3️⃣ recall — 본문·메모·태그에서 걸린 줄만 발췌
4️⃣ annotate — 페이지에 내 판단을 메모·태그로
5️⃣ overview — 뭘 기억 중인지, 뭐가 오래됐는지

안전장치는 원본보다 엄하게 갔습니다.
robots.txt는 파이썬 기본 파서가 `Allow: /` + `Disallow: /admin` 조합을 뚫길래
RFC 9309 longest-match를 직접 구현했고(테스트 12개), localhost·사내망(169.254.169.254 포함)은
DNS 해석 결과까지 보고 막습니다. JS는 실행하지 않습니다.

버린 것: 그래프 전체 덤프, delete 툴 3종, 무제한 길이
가져온 것: robots 존중 + 엔티티·관계·관찰 3원자

💡 활용 팁
릴리스 노트·요금표·API 문서처럼 **다시 보게 되는 페이지**만 remember_page로.
`page_changes`를 주기적으로 부르면 "이번 주에 뭐 바뀌었나"가 몇 줄로 끝납니다.
