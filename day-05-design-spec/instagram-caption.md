# 인스타 캡션 — Day 05 · design-spec

## 본문 (복사용)

디자인 파일에 색을 10종 쓴 줄, 구현하고 나서야 알게 됩니다.

주문/결제 화면 하나를 일부러 망쳐 놓고 돌려 봤습니다. 브라우저도 Figma 토큰도 없이 JSON 파일 하나로 —
**0/100 · 위반 17건 · 규칙 12종**. 고친 파일은 **100/100**.

오늘의 조합
· Figma-Context-MCP (MIT) — 한 번만 훑는 extractor, 두 노드 이상 쓰는 스타일만 표로 올리기, 같은 모양 접기
· Google Labs 의 `design-md` 스킬 (Apache-2.0) — DESIGN.md 의 다섯 칸과 "이름 + hex + 역할" 표기
코드는 한 줄도 복사하지 않고 설계와 문서 구조만 가져와 8개 툴로 다시 만들었습니다.

design-spec 이 잡아낸 것
1. 글자 #9AA0A6 on #F9FAFB → **2.53:1** (필요 4.5) → 고치는 색까지 제안: #6F7378 이면 4.56
2. 버튼 높이 32px · 아이콘 24×24 → 최소 44×44
3. "무선 이어폰" 위에 "품절" 이 **91% 겹침**
4. 폭 13px 간격 → 기준 4px 의 배수가 아님 → 12px
5. #0057FF 와 #0A5CFF — 눈으로 구분 안 되는 두 파랑

고친 뒤: 색 10 → 6종 · 글자 6 → 4단계 · 반경 5 → 2종 · 토큰 커버리지 40% → 100%
그리고 같은 파일에서 **DESIGN.md** 가 그대로 나옵니다 (분위기 / 색 역할 / 글자 사다리 / 부품 / 레이아웃).

정직하게: 그라디언트·이미지 위 글자의 대비와 `lineHeight: auto` 는 **판정하지 않습니다**고 결과에 적습니다.
모르는 것을 0으로 두지 않는 게 이 서버의 규칙입니다.
